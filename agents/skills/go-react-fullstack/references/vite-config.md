# Vite Configuration

## `frontend/vite.config.ts`

```typescript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:9800',
        changeOrigin: true,
      },
    },
  },
  build: {
    outDir: 'dist',
  },
});
```

## Key Notes

- Vite dev server runs at `:5173`, backend at `:9800`
- The proxy rewrites `/api/*` requests to the Go backend
- `npm run build` runs `tsc` type-check first, then `vite build`
- Output goes to `frontend/dist/` — Go's `embed.FS` reads this directory
- `"type": "module"` is required in `package.json` for ESM imports
